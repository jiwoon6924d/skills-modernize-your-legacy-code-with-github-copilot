# Student Account Management Test Plan

This plan captures the behavior currently implemented in the COBOL application and identifies unspecified behavior for stakeholder review. It is intended to guide later unit and integration tests for the Node.js replacement.

The current program has one in-memory balance initialized to `1000.00`, no student identification or account selection, and no persistence across process restarts. Balance and amount fields are `PIC 9(6)V99` (six integer digits and two implied decimal digits). Test results below are intentionally unexecuted: record the observed result and set Status to Pass or Fail when running the tests. Where expected behavior is marked for stakeholder decision, agree on the rule before treating the case as a migration acceptance test.
